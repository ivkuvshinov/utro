# Утренняя растяжка — PWA

Ежедневная растяжка груди, передней поверхности бедра и поясницы. Работает как обычный сайт и как устанавливаемое приложение на телефоне (PWA).

## Структура файлов

```
stretch-app/
├── index.html               # все экраны приложения
├── styles.css               # дизайн-система
├── exercises.js             # данные упражнений + SVG-иллюстрации
├── app.js                   # логика: таймер, навигация, история, тема
├── manifest.webmanifest     # описание PWA
├── sw.js                    # service worker (офлайн-режим)
└── icons/
    ├── icon-192.png         # иконка для устройств
    ├── icon-512.png
    ├── icon-maskable-512.png
    ├── apple-touch-icon.png
    └── favicon.png
```

## Как запустить локально

PWA требует HTTPS или localhost. Простейший способ:

```bash
cd stretch-app
python3 -m http.server 8000
# открыть http://localhost:8000 в браузере
```

Или через `npx`:

```bash
npx serve stretch-app
```

## Как задеплоить

### Вариант 1. Netlify Drop (самый быстрый, ~30 секунд)

1. Открыть https://app.netlify.com/drop
2. Перетащить папку `stretch-app` целиком в окно браузера
3. Получить ссылку вида `https://random-name.netlify.app`

Бесплатно, HTTPS из коробки. Можно подключить свой домен в настройках сайта.

### Вариант 2. GitHub Pages

```bash
# в папке stretch-app
git init
git add .
git commit -m "Initial commit"
git branch -M main
# создать репозиторий на github.com и запушить
git remote add origin https://github.com/USERNAME/stretch.git
git push -u origin main
```

В настройках репозитория → Pages → Source: Deploy from branch `main`, Folder: `/ (root)`.
Сайт станет доступен по адресу `https://USERNAME.github.io/stretch/`.

### Вариант 3. Vercel

```bash
npm i -g vercel
cd stretch-app
vercel
```

Следовать инструкциям. Получите ссылку с HTTPS.

## Установка на телефон как приложения

После деплоя:

**iOS (Safari):** нажать кнопку «Поделиться» → «На экран Домой»

**Android (Chrome):** меню (⋮) → «Установить приложение» / «Добавить на главный экран»

После установки приложение откроется в полноэкранном режиме без адресной строки браузера, появится в списке приложений и будет работать офлайн.

## Что внутри

- **Главный экран:** выбор длительности (30/40 мин), кнопка старта, streak-счётчик, история
- **Тренировка:** таймер с круговым прогрессом, иллюстрация позы, подсказка по технике, пауза/назад/вперёд, имя следующего упражнения, общий прогресс
- **Финальный экран:** статистика и возврат на главную
- **Превью:** просмотр всех упражнений программы

## Хранение данных

Все данные (история, streak, тема, выбранная длительность, состояние звука) хранятся локально в `localStorage` устройства. Никуда не отправляются. При очистке кеша браузера данные обнулятся.

## Кастомизация

- **Изменить упражнения:** редактируйте объект `EX` и массивы `PROGRAM_30` / `PROGRAM_40` в `exercises.js`
- **Поменять цветовую палитру:** меняйте CSS-переменные в `:root` и `[data-theme="dark"]` в начале `styles.css`
- **Изменить иконку:** замените файлы в `icons/` (или перегенерируйте, см. `make_icons.py`)
- **Длительность отдельных упражнений:** поле `duration` в секундах в каждом упражнении в `exercises.js`
